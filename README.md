# JRM minutes shadow archive (research only)

Pre-tip forecasts of the joint rotation model (research/projection_foundation/minutes_rebuild, design frozen at
6af02022b0fff19e24299e4b446463e711fe41b9), written before tip-off and never rewritten. Each file lists, per player, the JRM participation probability and
conditional minutes next to the frozen engine's published values for the same feed. `jrm_v1/MANIFEST.jsonl` holds the sha256 of every file; the git
push time on GitHub is the independent timestamp. Nothing here is published to SIFT and nothing here carries betting authority.
